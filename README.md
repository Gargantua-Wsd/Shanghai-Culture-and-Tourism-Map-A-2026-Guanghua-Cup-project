## 快速开始

### 第一步：阅读工作流文档

从 `workflow/00_工作流总览.md` 开始，了解项目全貌。

### 第二步：确认技术决策

阅读 `workflow/01_需求与技术确认.md`，向用户确认8个关键决策点。

### 第三步：开始开发

确认后，按 `workflow/04_开发阶段详细流程.md` 的顺序推进开发，
从 `workflow/05_提示词模板库.md` 复制对应提示词给AI执行。

### 第四步：质量验证

每个阶段完成后，对照 `workflow/06_质量检查清单.md` 逐项验证。
